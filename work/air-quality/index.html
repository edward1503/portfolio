01 / THE PROBLEM

A question worth solving.

Live sensor feeds and historical CSV files arrive with different structures and quality problems. Analysis needs a consistent, trustworthy layer of data.

02 / THE APPROACH

How it comes together.

Built an AWS Medallion pipeline: ingest into S3 Bronze, transform with Glue into Silver, validate with Athena-based checks, and publish Gold analytics tables through Step Functions.

  • Implemented Lambda ingestion and Glue transformations for live WAQI data and historical CSV sources in S3.
  • Built Athena-based checks for missing values, AQI ranges, city coverage, and freshness; Step Functions blocks Gold processing when quality checks fail.
03 / MY CONTRIBUTION

From idea to implementation.

Implemented ingestion and transformation scripts, checks for missing values, valid AQI ranges, city coverage and freshness, plus quality-gated orchestration and SNS notifications.

04 / THE TAKEAWAY

Quality before quantity.

The pipeline makes data quality part of the delivery process. A failed check blocks Gold processing before downstream analytics consume the data.
